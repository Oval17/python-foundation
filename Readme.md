# Python Foundation

Core Python for ML / backend work.

- [oop/](./oop/) — classes, `__init__`, methods, class variables (existing, kept)
- [typing/](./typing/) — annotations, generics, `Optional`
- [dataclasses/](./dataclasses/) — `@dataclass`, defaults, frozen models
- [generators-iterators/](./generators-iterators/) — `yield`, lazy iteration
- [decorators/](./decorators/) — closures, `functools.wraps`
- [context-managers/](./context-managers/) — `with`, `__enter__/__exit__`, `@contextmanager`
- [async-await/](./async-await/) — `asyncio`, `gather`

Each topic folder has a `README.md` and a runnable `example.py` (`python3 <topic>/example.py`).
Existing `oop/oop.py` and `oop/class-variable.py` are preserved.
